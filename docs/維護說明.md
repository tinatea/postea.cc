# 網站維護說明

Postèa 香語所是台北調香工作室的官方網站。頁面是繁體中文，網址是 [postea.cc](https://postea.cc)。

不用會寫程式。活動和最新消息都改 Google 試算表，不用改程式。

試算表：<https://docs.google.com/spreadsheets/d/1VIyh9mh76vbfhPye9M4UE1KYYs0ORjj-hxTGaeFwiGg>

每天台北時間早上 6:07，網站會自己讀一次試算表並更新。

想立刻公開：打開 [這個 Actions 頁面](https://github.com/tinatea/postea.cc/actions/workflows/pages.yml)，選 **Deploy to GitHub Pages**，按 **Run workflow**。

## 改活動

打開試算表的「活動」分頁。第一列是欄名，不要改欄名。多加一欄自己的筆記沒關係，網站會略過不認識的欄。整列空白會略過。

| 欄名 | 怎麼填 |
| --- | --- |
| 活動代號 | 英文，不要重複。例如 `osmanthus-tea-room-2026-11` |
| 活動名稱 | 給參加者看的名稱 |
| 日期 | `2026-11-21` 這種，年-月-日。不要寫 `11/21` |
| 開始時間 | `14:00` |
| 結束時間 | `16:15` |
| 地點 | 還沒定就寫 `台北市（地點確認中）` |
| 費用 | 例如 `NT$800／人` |
| 人數 | 例如 `限額 10 人，確定開課`。11 月 21 日這一場沒有最低人數，人再少也會開。 |
| 帶走的東西 | 參加者會帶走什麼 |
| 報名連結 | 用表單報名才填，要 `https://` 開頭。用 LINE 報名就留空。 |
| 主題色 | `#D9A441` 這種六碼色碼。沒有可以留空 |
| 活動介紹 | 給參加者看的短文。想分段，就在同一個格子裡空一行。不要寫成本、租金、內部討論 |
| 發布狀態 | 可不加這一欄。`公開` 或 `草稿`。空白當成公開。 |
| 報名狀態 | 可不加。空白、`即將開放`、`報名中`、`已額滿`、`已取消`。 |
| 報名開放時間 | 可不加。`2026-11-01` 或 `2026-11-01 10:00`。 |
| 報名截止時間 | 可不加。空白就是活動開始時間。 |
| 報名方式 | 可不加。`LINE` 或 `表單`。 |
| 封面圖 | 可不加。要換圖再填 `https://` 開頭的網址。空白時，若這場已經有網站內建的主題圖，就用那張。 |

試算表裡已經寫好的句子，網站會照登，不會自動改寫。請把「活動」的人數，和「最新消息」內文裡還在寫最低人數的地方，改成 `限額 10 人，確定開課`。

### 發布和報名

上面五欄沒有也沒關係，建置不會失敗。寫錯的時間會當成沒填，也不會讓整份表作廢。

全部都是草稿時，網站不會改去用備用檔，畫面上就是沒有活動。

狀態用台北時間，在每次建置時重算。每天早上 6:07 會更新一次。順序是：已取消、已結束、報名截止、即將開放、已額滿、報名中。

| 畫面上的狀態 | 什麼時候 |
| --- | --- |
| 已取消 | 「報名狀態」填了已取消。不能報名。 |
| 已結束 | 過了結束時間。沒寫結束時間，就到那天結束。 |
| 報名截止 | 到了截止時間。沒寫截止時間，就是活動一開始。 |
| 即將開放 | 沒寫開放時間、還沒到開放時間、狀態空白，或寫了不認識的字。 |
| 已額滿 | 已經開放，而且填了已額滿。沒有候補名單。 |
| 報名中 | 填了報名中，而且在開放與截止之間，還要有入口。 |

入口的規則：

- 方式是 `LINE`：按鈕是「用 LINE 報名」。沒有表單網址也可以。
- 方式是 `表單`，或方式空白但報名連結是 `https://` 開頭：按鈕是「前往報名」，會開新視窗。
- 寫了報名中，可是沒有 LINE、也沒有有效網址：仍是即將開放，不會變成可報名。
- 已額滿或報名中，如果還沒到開放時間、或沒填開放時間：仍是即將開放。

即將開放、報名截止、已取消，按鈕是「LINE 詢問」。LINE 按鈕旁邊會寫：開啟 LINE 不代表報名完成，以工作室確認為準。已額滿是「查看其他場次」。已結束是「查看近期活動」。

只寫日期、沒寫時間：開放從那天 00:00 起算，截止到那天 23:59。截止如果寫得比活動結束還晚，會收到結束時間，不會晚過結束。

狀態是文字，不是只靠顏色。頁面不顯示剩餘名額，也不顯示最低開課人數。人數欄寫什麼，頁面就顯示什麼。

日期寫錯，或主題色不是 `#` 加六個英數，這次建置會整份改用倉庫裡的備用檔，網站不會空白。建置紀錄會寫原因。

活動當天、結束時間還沒到，首頁仍會出現這一場。過了結束時間之後，下一次建置起，首頁不再把它當下一場。沒寫結束時間，就到那天結束。月曆那一天還是看得到。不用搬列、也不用刪。

## 在 GitHub 網頁上改備用檔

## 備用：活動檔

只在試算表讀不到時才用 [`src/data/events.yml`](../src/data/events.yml)。

複製檔案裡現有的一整段，貼在清單最上面，改成新的內容。日期和時間兩邊要有引號，例如 `"2026-12-19"`、`"14:00"`。

| 欄位 | 填什麼 |
| --- | --- |
| `id` | 英文代號，不要重複。例如 `spice-winter-2026-12` |
| `title` | 活動名稱 |
| `date` | `"YYYY-MM-DD"` |
| `startTime` / `endTime` | `"14:00"` 這種，要加引號 |
| `venue` | 地點。還沒定就寫 `台北市（地點確認中）` |
| `price` | 例如 `NT$800／人` |
| `capacity` | 例如 `限額 10 人，確定開課` |
| `description` | 給參加者看的短文。不要寫成本、租金、內部討論 |
| `takeHome` | 參加者會帶走什麼 |
| `registrationUrl` | Google 表單網址。還沒有就留 `""` |
| `accentColor` | 可省略。這場要有自己的主題色時再填，例如 `"#D9A441"` |

`registrationUrl` 留 `""` 時，不會出現「前往報名」。備用檔也可以加 `publishStatus`、`signupStatus`、`signupOpen`、`signupClose`、`signupMethod`，意思和試算表那五欄一樣。沒寫時，還沒開始的場次是「即將開放」，旁邊是 LINE 詢問（連結寫在 `site.yml` 的 `lineUrl`）。

### 過了的活動

不用搬檔案，也不用刪。以台北時間重算：過了結束時間，狀態變成已結束，首頁不再把它當下一場。月曆裡那一天還在。沒寫結束時間，就到那天結束才算。

網站是靜態的。狀態和最新消息都在重新建置時更新。每天台北時間早上 6:07 會自動建置一次。推上 `main` 也會建置。想立刻更新，用上面的 **Run workflow**。

最新消息的備用檔是 [`src/data/news.yml`](../src/data/news.yml)，平常不用改。

## 新增一場活動紀錄

1. 照片放進 `public/images/recaps/`。
2. 複製 [`content/recaps/_example.md`](../content/recaps/_example.md)。
3. 新檔名不要用底線開頭，例如 `2026-11-21-osmanthus.md`。底線開頭的檔案不會出現在網站上。
4. 刪掉 `published: false` 那一行，改標題、日期、內文和照片路徑。
5. 存檔並推上 `main`。

## 改課程

兩堂課和「怎麼選？」寫在 [`src/data/offerings.yml`](../src/data/offerings.yml)。

- 調香探索與體驗：一對一 NT$2,000；兩人同行每人 NT$1,800；三至四人同行每人 NT$1,600。時長約 1.5 至 2 小時。成品是 30ml 淡香水或 50ml 空間噴霧（二選一）。按鈕是「用 LINE 預約」。
- 空間噴霧的容量寫在 `sprayVolume`。現在是 `50ml`。改這一欄，頁面的「50ml 空間噴霧」會跟著改。不要寫底線。
- 每月主題調香：每人 NT$800，帶走 10ml 主題香水。按鈕是「看本月主題」，連到月曆。

單場的日期、地點、報名仍改試算表的「活動」分頁。那一欄的費用若改了，這裡的「每人 NT$800」也要一起改。

## 改顏色或字體

只改 [`src/styles/theme.css`](../src/styles/theme.css) 最上面的色碼和字體。

目前使用的色票：頁面淺灰 `#FAFAFA`、卡片暖米 `#F2EEEB`、內文 `#454545`。標誌青 `#62A297` 只用在首頁標誌區和頁尾外框，不要在這塊青色上放白色小字，也不要拿來當資訊卡的底色。主要報名按鈕是山茶紅 `#AF3332`、白字。次要按鈕、連結和焦點框是深青 `#3A7268`。標籤鼠尾草綠 `#66704F` 用白字。每月主題色用 `#D9A441`，上面的字用深褐 `#3A2C10`。單場若要蓋過主題色，寫在該場的 `accentColor`。

## 上線前 Tina 要自己做的事

這些設定在 GitHub 與網域註冊商，程式沒辦法代為打開。

1. 把這個 Pull Request 合併進 `main`（先不要在沒看過頁面時合併）。
2. 打開倉庫 **Settings → Pages → Build and deployment**，Source 選 **GitHub Actions**。若沒選這個，上面的自動部署不會生效。
3. 同一頁的 **Custom domain** 填 `postea.cc`，按 Save。  
   用 GitHub Actions 發佈時，GitHub **不會讀**倉庫裡的 `CNAME` 檔（檔案仍留著，給人看、也給以後改回從分支發佈時用）。網域一定要在這個欄位存檔。
4. **先**在 GitHub 存好自訂網域，**再**到註冊商改 DNS，避免網域空窗被人占用。建議再到 GitHub 的網域驗證畫面，把它給的 TXT 紀錄加進 DNS。
5. 在註冊 `postea.cc` 的地方設定下面的紀錄。若原本有停放頁、轉址或別組 A／CNAME，先刪掉，不要和這些並存。

   **apex（`postea.cc`，主機名稱 `@` 或留空）** — 四筆 A：

   | 類型 | 名稱 | 值 |
   | --- | --- | --- |
   | A | `@` | `185.199.108.153` |
   | A | `@` | `185.199.109.153` |
   | A | `@` | `185.199.110.153` |
   | A | `@` | `185.199.111.153` |

   以及四筆 AAAA（IPv6）：

   | 類型 | 名稱 | 值 |
   | --- | --- | --- |
   | AAAA | `@` | `2606:50c0:8000::153` |
   | AAAA | `@` | `2606:50c0:8001::153` |
   | AAAA | `@` | `2606:50c0:8002::153` |
   | AAAA | `@` | `2606:50c0:8003::153` |

   如果註冊商不讓 apex 填 A、只提供 ALIAS 或 ANAME：改指到 `tinatea.github.io`，**不要再加**上面的 A／AAAA。

   **www**

   | 類型 | 名稱 | 值 |
   | --- | --- | --- |
   | CNAME | `www` | `tinatea.github.io` |

   CNAME 要指到 `tinatea.github.io`，不要加上倉庫名稱，也不要指到 `*.pages.github.io`。

6. DNS 生效後（有時要數小時，最長約一天），回到 **Settings → Pages**，勾選 **Enforce HTTPS**。憑證還沒簽好時這個選項會是灰的，等它可勾再勾。勾了之後，`http://` 會轉成 `https://`。`www.postea.cc` 會轉到 `postea.cc`。
